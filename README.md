# RageBaitGame
This game will ragebait you so much that you will want to quit. As soon as you fall off (which is very likely), you will be taken back to spawn and be asked if you have the will to rebound, or to "bounce back" to where you were. Point of the game is to collect all the stars and to get to the top.


parkour game

Play using W to go forward, A to go left, S to go back, D to go right, L Shift to sprint (any direction), Space to jump.
